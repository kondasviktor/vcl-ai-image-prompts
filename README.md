# VCL Image Prompts

**Copy-paste visual prompt recipes for ChatGPT, Gemini, Grok, and Microsoft AI (MAI Playground) chats** — by [Vibe Coder's Life](https://vibecoderslife.com/?utm_source=github&utm_medium=readme&utm_campaign=image-prompts).

> Slash tokens like `/xray` and `/blueprint` are **memorable shorthand, not official commands**. If a chat ignores the `/`, paste the expanded prompt in the recipe.

People sell lists like this on Gumroad. This catalog is **free** — 100+ shorthands, same recipe in four chats.

📬 **[Newsletter](https://vibecoderslife.com/?utm_source=github&utm_medium=readme&utm_campaign=image-prompts#subscribe-email)** · ⭐ Star if you want it maintained · **[117-command catalog](commands/catalog.md)**

## Quick start

1. Pick a style in the gallery (or a row in the [catalog](commands/catalog.md)).
2. Open the recipe and copy the **Better prompt**.
3. Paste into **ChatGPT**, **Gemini**, **Grok**, or **[Microsoft AI (MAI Playground)](https://playground.microsoft.ai/chat)** — pick **MAI-Image-2.6** or **2.5**.

## Before → after

Same subject, different prompt. Style demos so you can see the jump — **not** a dated ChatGPT / Gemini / Grok / MAI bake-off. Run a recipe in those four chats and drop dated files next to these (`chatgpt.png`, `gemini.png`, `grok.png`, `mai.png`).
