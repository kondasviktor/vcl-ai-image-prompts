# Examples

## Style demos (in the README)

Each featured recipe has a pair in this folder:

```text
examples/<recipe-slug>/before.png   # plain subject
examples/<recipe-slug>/demo.png     # after applying the recipe look
```

These are **look demos**, not a dated four-chat bake-off. Do not treat them as proof that ChatGPT / Gemini / Grok / MAI produced that file.

## Four-chat outputs (still open)

After you generate the **same expanded prompt** in each chat:

```text
examples/<recipe-slug>/chatgpt.png
examples/<recipe-slug>/gemini.png
examples/<recipe-slug>/grok.png
examples/<recipe-slug>/mai.png
```

**MAI** = [Microsoft AI (MAI Playground)](https://playground.microsoft.ai/chat) — choose **MAI-Image-2.6** or **MAI-Image-2.5**. Prefer the expanded prompt — slash tokens are not an official Microsoft API.

Do **not** commit placeholder or stock photos as if they were model outputs. Recipes stay `Tested: pending` until dated chat outputs exist.
