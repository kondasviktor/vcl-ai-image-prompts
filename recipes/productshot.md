# Product shot — wireless earbuds

**Command:** `/productshot`

## What it does

Ecommerce-ready hero: controlled light, true materials, clipping-path energy.

## Works best for

Hardware, bottles, shoes, packaging. Say no hand model if you do not want hands.

## Quick prompt

```text
/productshot wireless earbuds
```

`/productshot` is shorthand. If the model ignores the slash token, use the expanded prompt.

## Better prompt

```text
Create a commercial product photograph of a pair of matte-black wireless earbuds in an open charging case.

Softbox lighting, subtle reflection on a seamless light-gray cyclorama, 16:9.
Sharp, catalog-ready, no people, no logo watermarks, no text overlays.
```
