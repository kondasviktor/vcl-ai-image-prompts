# X-ray — mechanical keyboard

**Command:** `/xray`

## What it does

Keeps the exterior silhouette while showing internals through a semi-transparent shell.

## Works best for

Cars, electronics, architecture, machinery, anatomy, consumer products.

## Quick prompt

```text
/xray mechanical keyboard
```

`/xray` is shorthand. If the model ignores the slash token, use the expanded prompt.

## Better prompt

```text
Create a detailed X-ray visualization of a modern mechanical keyboard.

Show:
- switches
- PCB
- stabilizers
- plate
- USB controller
- wiring
- case construction

Semi-transparent outer shell.
Clean technical visualization.
Dark neutral background.
No unnecessary text.
16:9.
```
