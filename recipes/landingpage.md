# Landing page — indie SaaS waitlist

**Command:** `/landingpage`

## What it does

A full-page marketing screenshot: hero, one CTA, social proof strip — not a dashboard.

## Works best for

Waitlists, courses, indie tools. Say desktop 1440-wide vibe.

## Quick prompt

```text
/landingpage indie SaaS waitlist
```

`/landingpage` is shorthand. If the model ignores the slash token, use the expanded prompt.

## Better prompt

```text
Create a desktop screenshot of a marketing landing page for an indie developer tool.

Above the fold: short headline, one sentence, email waitlist field, primary button.
Below: three benefit tiles. Dark theme, tasteful, not a Dribbble clutter dump.
16:9 crop of the browser content area. No real company trademarks.
```
